# Reporting a vulnerability

Please use [private vulnerability reporting](https://github.com/dylan-murray/iap-portal/security/advisories/new)
to report authentication bypasses, exposed credentials, or other security issues.
Do not include exploit details or secrets in public issues or pull requests.
If private reporting is not available yet, wait for it to be enabled before
sharing sensitive details publicly.

Include the affected commit or version, deployment configuration with secrets
removed, reproduction steps, and expected versus observed behavior.

The project is pre-release. Security fixes target the latest main branch until
versioned releases establish a support policy. See the [security model](docs/SECURITY.md)
for implemented controls, validation evidence, and known limitations.
